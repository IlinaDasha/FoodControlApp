# FoodControlApp
FoodControlApp - Android-приложение для контроля питания и подсчета калорий. 
Приложение помогает пользователям следить за своим питанием и подсчитывать потребляемое число калорий. 

# Возможности приложения
Приложение позволит пользователю формировать общий список продуктов с их массой и пищевой энергетической ценностью в ккал, а также записывать каждый свой прием пищи.

В процессе добавлении записи пользователь сможет выбирать продукты из общего списка продуктов и самостоятельно указывать их количество. (например, если пользователь съел 250 грамм курицы, а в списке курица указана с массой 100 грамм, то пользователь может указать коэффициент 2.5 для внесения в рацион полной порции приема пищи).

Будет реализована возможность просматривать, добавлять, удалять и редактировать приемы пищи. Каждый прием пищи о список продуктов, их количество (с килокалорийностью), а также общее число килокалорий, потребляемых в рамках данного приема.

"Планируется" также добавить возможность пользователя указывать желаемое количество килокалорий для потребления в день. В зависимости от этого значения приложение будет отображать разницу между запланированным и фактическим количеством килокалорий.
