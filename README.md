# FoodControlApp
FoodControlApp - Android-приложение для конроля питания и подсчета калорий. 
Приложение помогает пользователям следить за своим питанием и подсчитывать потребляемое число калорий. 

# Возможности приложения
Пользователь может формировать общий список продуктов с их массой и пищевой энергиетической ценностью в ккал, а также записывать каждый свой прием пищи. 
В процессе добавлении записи пользователь выбирает продукты из общего списка продуктов и самостоятельно указывает их количество. (например, если пользователь съел 250 грамм курицы, а в списке курица указана с массой 100 грамм, то пользователь может указать коэффициент 2.5 для внесения в рацион полной порции приема пищи)
Также приложение позволяет просматривать, добавлять, удалять и редактировать приемы пищи. Каждый прием пищи отображает список продуктов, их количество (с килокалорийностью), а также общее число килокалорий, потребляемых в рамках данного приема.
??? (Пользователь имеет возможность указывать желаемое количество килокалорий для потребления в день. В зависимости от этого значения приложение отображает разницу между запланированным и фактическим количеством килокалорий.)
